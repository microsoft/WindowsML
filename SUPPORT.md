# Support

## Filing issues

This repo hosts the official Windows ML samples. **File issues here** when:

- A sample in this repo doesn't build, doesn't run, or behaves unexpectedly.
- You'd like to request a new sample or an addition to an existing one.
- You have a question about how a sample works.

[Open an issue in this repo →](../../issues/new/choose)

Please search [existing issues](../../issues) first to avoid duplicates.

## Where to file other kinds of issues

| Issue type | Where to file |
|---|---|
| Windows ML **runtime / API** bug or feature request (not specific to a sample) | [microsoft/WindowsAppSDK](https://github.com/microsoft/WindowsAppSDK/issues) |
| ONNX Runtime bug or feature request | [microsoft/onnxruntime](https://github.com/microsoft/onnxruntime/issues) |
| ONNX Runtime GenAI bug or feature request | [microsoft/onnxruntime-genai](https://github.com/microsoft/onnxruntime-genai/issues) |
| Windows ML CLI bug or feature request | [aka.ms/winmlcli](https://aka.ms/winmlcli) |
| Documentation feedback | The "Feedback" control at the bottom of any [Windows ML docs](https://learn.microsoft.com/windows/ai/new-windows-ml/overview) page |
| Security vulnerability | **Do not file a public issue.** See [SECURITY.md](SECURITY.md). |
